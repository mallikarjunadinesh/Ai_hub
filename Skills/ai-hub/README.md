# AI HUB

## Overview

AI HUB is a repository discovery portal that automatically scans the AI repository and generates an interactive catalog of all:

- Agents
- Prompts
- Skills

The generated portal helps users quickly discover AI capabilities, understand their purpose, and navigate to the relevant documentation.

## Features

- Automatic repository scanning
- Agent catalog
- Prompt catalog
- Skill catalog
- Category-based navigation
- Global search
- Relationship discovery
- Interactive HTML dashboard

## Generated Output

The generated website is created under:

output/

Open `output/index.html` in a browser to explore AI HUB.
