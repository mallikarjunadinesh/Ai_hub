# AI HUB

## Purpose

AI HUB automatically scans the repository and builds a centralized portal where users can easily discover and understand available AI capabilities.

Instead of manually browsing folders, users can search, filter, and explore Agents, Prompts, and Skills from a single interface.

---

## When to Use

Use AI HUB when you want to:

- Discover available Agents
- Explore available Skills
- Browse Prompts
- Understand what an Agent or Skill does
- Find related Agents, Skills, and Prompts
- Navigate the AI repository visually

---

## Features

AI HUB automatically:

- Scans the repository
- Detects Agents
- Detects Prompts
- Detects Skills
- Builds relationships between them
- Generates an interactive HTML portal
- Organizes content into categories
- Supports global search

---

## Output

The generated portal is created under:

```
Skills/ai-hub/output/
```

Open:

```
output/index.html
```

to explore the generated AI HUB.

---

## Notes

AI HUB is a discovery and navigation portal.

It does not replace the original documentation. Instead, it helps users quickly identify the right Agent, Prompt, or Skill and provides links to the original documentation for detailed implementation guidance.
